# Agent system

Not built. The brief asks for specialised agents sharing a research workspace. Two research agents were used once, during the Nov. 20 research pass, and their findings are in `RESEARCH_PLAYOFF_PREDICTOR.md`. Nothing in the running product uses an agent.

Why not yet: agents need somewhere to run on a schedule and a store for findings with sources and timestamps. The project has neither until it lives in a repository with scheduled runs. When it does, the first agent worth having is a news and injury reader feeding the red-team panel, with each finding stored as claim, source, time, affected teams and expiry.
