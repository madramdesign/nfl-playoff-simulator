# V2 — Adversarial check of provider terms and prices

Verifier: red-team agent, Nov. 25, 2026. All pages read on 2026-11-25 with `curl` (User-Agent `nfl-universe-research/1.0`, no cookies, no keys, no sign-in) or WebFetch. Raw copies were saved in the session scratchpad (`scratchpad/v2dl/`), not in the repository. Quotes are at most 15 words. "Free public page" means the current non-commercial, ad-free public NFL Universe page; "commercial" means a future paid or ad-supported product.

Verdict scale: CONFIRMED (the provider's own page says it), PARTLY (core right, a detail wrong or missing), REFUTED (the page says otherwise), UNVERIFIABLE (could not read the provider's own page; reason given).

## 2. Sleeper — PARTLY (both texts CONFIRMED; the §11.1 wording is stricter than claimed; which governs is genuinely ambiguous)

Pages read (2026-11-25): https://sleeper.com/terms (redirects to https://support.sleeper.com/en/articles/5486620-general-terms-of-use) ; https://docs.sleeper.com/ (HTTP `Last-Modified: Wed, 21 Oct 2026`). Raw copies: `v/raw/sleeper_terms.txt`, `v/raw/sleeper_docs.txt`.

- Date: "Last Updated: November 17, 2026, 2026" (sic, year doubled). CONFIRMED.
- §11.1 does NOT say "or other approval". Its bullets require "the express written consent of Sleeper" for: crawling/scraping; accessing data "through any automated means, bot, script"; and, separately, "Use our Services for any commercial or business purpose". PARTLY — the claim conflates 11.1 with 11.3.
- §11.3: no third party may "access, use, scrape, crawl, query, or retrieve any data" except under "a separate written agreement executed by Sleeper, or other approval given by Sleeper, expressly authorizing that access". CONFIRMED ("or other approval" is only in 11.3).
- Docs: "read-only HTTP API that is free to use for non-commercial purposes"; "stay under 1000 API calls per minute, otherwise, you risk being IP-blocked"; commercial use: contact Sleeper "to discuss licensing". Trending section: "Please give attribution to Sleeper" for trending data. `/players/nfl`: "intended only to be used once per day at most". CONFIRMED. New detail not in the claim: `/players/<sport>` now takes `position` and `active` filters.
- Reading (not legal advice): "Services" is defined as Sleeper's apps and website "through which we offer ... tools, content, products and services"; api.sleeper.app plausibly falls inside it. The docs page is Sleeper's own published, specific statement that the API is "free to use for non-commercial purposes" — a reasonable candidate for 11.3's "other approval ... expressly authorizing that access", and the specific usually controls the general. Against that: the ToS is newer (Nov. 17 vs docs Oct. 21), §11.1's bullets demand "express written consent" (a public web page addressed to no one is a weak fit), and the new text targets third-party tools (credential sharing, league syncing). Net: the current use (3 unauthenticated calls an hour to public trending/state endpoints, credited, non-commercial) sits within the docs' grant and is low-risk; anything commercial, any league/user data at scale, or any scraping of sleeper.com is not covered by either text. A one-line email to Sleeper asking for written confirmation would remove the ambiguity; record the answer in the registry.
- Repository check: `lib/fabric/adapters/sleeper.js` and `docs/NFL_DATA_SOURCE_REGISTRY.md` record only the docs page; neither mentions the Nov. 17 ToS §11.

## 5. Official NFL podcast feeds (Omny) — CONFIRMED for all six

Feeds read (2026-11-25, first 200 lines only, 23–33 KB each; URLs from `lib/fabric/adapters/media.js` lines 106–111): the six `https://www.omnycontent.com/d/playlist/e73c998e-6e60-432f-8610-ae210140c5b1/.../podcast.rss` feeds for NFL Daily with Gregg Rosenthal, NFL: Good Morning Football, NFL: The Insiders, NFL News Hub, The NFL Report, NFL Game Previews. - Copyright: each of the six channels carries the same single `<copyright>`: "2026 iHeartMedia, Inc. © Any use of this intellectual property for text and data mining or computational analysis including as training material for artificial intelligence systems is strictly prohibited without express written consent from iHeartMedia". CONFIRMED (quoted precisely as a fact; it bars three things: text and data mining, computational analysis, AI training).
- Transcripts: all six carry `podcast:transcript` tags, each episode in three formats (`application/srt`, `text/vtt`, `text/plain`) at `api.omny.fm/orgs/<NFL org>/clips/<clip>/transcript?format=...`. In the 40 items read, 34 had transcripts (the item cut off at line 200 in each feed explains most of the gap). CONFIRMED.
- `<itunes:author>` is "NFL", but the rights line names iHeartMedia (Omny's owner/distributor), not the NFL. Both should be named as rights holders.
- Consequence (stronger than the claim): "computational analysis" is broad. Fetching a transcript and running it through an LLM to extract claims, summarise, or search is computational analysis of the transcript, so the `podcast:transcript` tags are NOT a licence to build a transcript/claim-tracking feature on these shows without iHeartMedia's written consent. Listing episodes (title, date, link) and playing the feed's own audio — what the repository does now — is ordinary podcast-app use. Reading the episode `<title>`/`<description>` for display is fine; running NLP over the descriptions is arguably also "computational analysis" and should be kept to plain display.
