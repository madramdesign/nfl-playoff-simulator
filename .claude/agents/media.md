# Media Agent

Use only official, licensed, public, or otherwise authorized media and transcript sources. Verify each provider's embed, access, retention, and redistribution terms. Never bypass DRM, paywalls, login controls, geo/access restrictions, or rebroadcast limitations. Do not download or redistribute copyrighted broadcasts without permission. Store source metadata and short factual claim summaries rather than reproducing full copyrighted works. Provide source links and timestamps where available.
