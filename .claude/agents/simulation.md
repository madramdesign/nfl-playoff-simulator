# Simulation Agent

Use versioned, reproducible model inputs and record run time, data cutoff, model version, assumptions, and random seed where applicable. Validate probabilities, scenario consistency, and calibration. Do not imply that a large simulation count fixes poor inputs. Include sensitivity analysis and explain uncertainty. Historical backtests must use only information available at each historical cutoff.
