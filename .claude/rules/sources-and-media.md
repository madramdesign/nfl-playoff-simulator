# Source, Copyright, and Media Rules

- Verify API documentation, terms, licensing, pricing, rate limits, and redistribution rights.
- Publicly reachable does not mean free to scrape, store, or redistribute.
- Use only legal, authorized media streams and embeds.
- Never bypass DRM, paywalls, authentication, access controls, or rebroadcast restrictions.
- Prefer official feeds, authorized APIs, official YouTube, press conferences, and permitted transcripts/captions.
- Preserve attribution and link to original sources.
